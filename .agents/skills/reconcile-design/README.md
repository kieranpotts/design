# Reconcile design

Compares the design docs against the real production system, and
drafts a design change to fix any drift it finds.

## How to invoke

> Reconcile design

> The deployment moved to multi-region last month, but the physical view
> still shows one region.

## Recommended models

A mid-tier model is sufficient for this skill, though comparing the design
views against a live system is analysis, not bookkeeping. Escalate to a
stronger reasoning model for large systems or subtle drift.
